# Mẫu thư mục kết quả `docs/website/`

```
docs/website/
├── 01-thi-truong.md      # chân dung khách, từ khoá, kênh, mùa vụ
├── 02-doi-thu.md         # 3–5 đối thủ đã chọn, bảng REACH, bảng Lấy/Tránh
├── 02-doi-thu.csv        # dữ liệu thô 10–15 ứng viên (đầu vào reach_score.py)
├── 03-brief.md           # brief duyệt trước khi code (mẫu trong web-brief)
├── 04-thiet-ke.md        # màu, font, bố cục từng section, ảnh/video cần có
├── 07-kiem-tra.md        # nhật ký 5 vòng kiểm tra: lỗi, cách sửa, commit
├── 08-trien-khai.md      # hosting, DNS, biến môi trường, sao lưu
└── COWORK-*.md           # tài liệu giao việc cho Cowork (thao tác trình duyệt)
```

Mỗi file mở đầu bằng 3 dòng: ngày, trạng thái (nháp / đã duyệt), người duyệt. Cuối file là mục
"Cần xác nhận" đánh số để người dùng trả lời nhanh.
